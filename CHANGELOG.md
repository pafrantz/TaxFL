# CHANGELOG — TaxFL v10 → v11

This changelog records the corrections, additions, and reconciliations made between the v10
working paper and the v11 reproducibility package. The guiding principle is that every empirical
claim in v11 is backed by a number produced by the code in this repository.

## Summary

v11 does not weaken the framework — it makes the empirical story **more positive and more
honest**. After correcting an evaluation artifact in the Cora benchmark, implementing the
SCAFFOLD optimizer that v10 recommended but never ran, and regenerating the scale experiments
from current code, federation is shown to help (i) at scale (5–10 jurisdictions), (ii) through
graph structure over linear models, and (iii) via SCAFFOLD where naive averaging caused negative
transfer. The headline framing shifts from "federation always helps" (unsupported) to a measured
**utility frontier**.

## Bugs fixed

1. **Cora benchmark measured training accuracy, not generalization.**
   `taxfl.py` trained each client on its own label-skewed node mask and evaluated accuracy on the
   *same* mask, with no held-out test set. This inflated the local-only number (~0.99) and made
   federation appear to incur a utility cost.
   *Fix* (`taxfl_cora_v11.py`): a single global, class-balanced test split shared by all methods.
   *Effect*: honest local-only accuracy drops to 0.508 ± 0.006; FedAvg/FedProx/SCAFFOLD reach
   0.80–0.82, matching/exceeding the centralized upper bound (0.796). SCAFFOLD leads
   (0.819 ± 0.013). The benchmark now supports, rather than undercuts, the federated thesis.
   *Note*: the domain pipeline (`taxfl_experiment.py::to_pyg`/`evaluate`) already used a proper
   60/20/20 split and is **not** affected by this artifact.

2. **All-fraud silos produce NaN and corrupt aggregation.**
   COAF, MP, and PF are constructed with all-positive labels (`silo_labels[...] = np.ones`).
   `class_weight_tensor` then assigns weight 0 to the fraud class, and the resulting NaN updates
   propagate through `fedavg`. `run_intra_country` crashes at the "+COAF+MP" configuration.
   *Fix*: treat all-fraud silos as **Tier-2 consumers** (no training contribution), consistent
   with the framework's tiered-participation design. Consequently "+COAF+MP" and "full federation"
   are, in training terms, identical to the bilateral RFB+Bancos federation.

3. **Intra-country ablation switched the evaluation target between rows.**
   `run_intra_country` evaluated "RFB-only" on RFB but later configurations on Bancos
   (`ref_silo = 'Bancos' if ...`), making the apparent "0.725 → 0.793" improvement an
   apples-to-oranges comparison.
   *Fix*: evaluate every configuration on a single fixed target (see `intra_bilateral.py`).

4. **SCAFFOLD recommended but never implemented for the domain.**
   v10 §5.1.1 recommends SCAFFOLD as the default cross-border optimizer, but only FedAvg/FedProx
   were ever run on the domain data.
   *Fix* (`taxfl_scaffold.py`): SCAFFOLD (control variates, option II) integrated into the real
   pipeline. Measured: SCAFFOLD removes essentially all of the FedAvg/FedProx negative-transfer
   penalty in the cross-border setting (≈ local-only; >> FedAvg/FedProx).

## Numbers reconciled (code now differs from v10 tables)

The v10 tables were generated by an earlier code version (docstrings reference "v9.1"). The
current code produces different — generally stronger — results. All tables are regenerated:

- **Cora (Appendix A)**: replaced with the corrected global-split result (see bug 1).
- **3-jur main (Appendix B.4)**: current code gives FedAvg AUC 0.760 ± 0.031 / F1 0.251 (v10
  reported 0.568 / 0.079). On a held-out split, local-only beats FedAvg/FedProx on jurisdiction C
  (negative transfer); SCAFFOLD closes the gap (Appendix B.0).
- **Scale (Appendix B.3)**: at 5 and 10 jurisdictions, federation now **exceeds** local-only on
  AUC and AUPRC (5 jur: 0.784/0.786 vs 0.716; 10 jur: 0.786/0.789 vs 0.749). The earlier
  "degrades under scale" reading was an artifact of the prior code version.
- **Loss comparison (Appendix B.7.2)**: "standard" and "weighted" cross-entropy are identical
  because `local_train` already applies inverse-frequency class weights; the claim that weighted-CE
  is a distinct improvement is corrected. Focal loss collapses (F1 0.000).
- **Typology ablation (§9.6)**: GraphSAGE federated RFB+Bancos vs LogReg gives mean +0.272 AUC and
  +25.3 pp scheme-level recall, with the largest gains on split-signal typologies (T1 +45 pp,
  T2 +50 pp, T3 +40 pp) and T6 +16.7 pp.
- **Table 1 (§9.4)**: the legacy table used a 19,470-node intra configuration that the current
  default (500 nodes) does not reproduce. Regenerated isolated LogReg (5 seeds, default config):
  RFB 0.589 ± 0.073, Bancos 0.611 ± 0.072, COAF/MP/PF 0.500 / F1 0.000. The dominant effect is
  architectural (linear → graph: RFB 0.589→0.827, Bancos 0.611→0.908), not isolation → federation.

## Methodology improvements

- Single **global test split** shared across methods (Cora; available in the harness for the
  domain experiments).
- **Confidence intervals** (95%, t-based) reported alongside means, replacing bare standard
  deviations.
- **Stratified splits** for low base-rate settings (reduce variance from sparse positives).
- **AUPRC** promoted to primary metric under ~6% fraud (AUC and F1@0.5 are secondary).
- **SCAFFOLD** added as a selectable optimizer.
